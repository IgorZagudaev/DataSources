# DataSources
Отображение источников данных докладов по показателям справок

Стек: React + Vite (фронтенд), PHP 8 + PostgreSQL (бэкенд, `backend/api/`).

## Режимы работы

Приложение работает в одном из двух режимов:

- `local` — данные хранятся в localStorage браузера;
- `api` — данные хранятся в PostgreSQL, обмен идёт через `backend/api/index.php`.

Режим задаётся настройкой `default_mode` в `backend/api/config.php`
(или в `backend/api/config.local.php`, см. ниже) — значение с сервера имеет
приоритет над тем, что лежит в localStorage.

## Локальный запуск

Нужны два процесса: PHP-API и Vite. Apache для разработки не требуется.

### 1. Настройки БД

Пароль и локальные параметры держите в `backend/api/config.local.php`
(файл в `.gitignore`, в репозиторий не попадает):

```php
<?php
return [
    'database' => ['password' => 'ваш_пароль'],
    'app' => [
        'default_mode' => 'api',   // работать с PostgreSQL
        'sql_logging' => false,    // не писать sql.log
        'admin_ips' => ['127.0.0.1', '::1'],  // кому разрешено редактировать
    ],
];
```

Значения отсюда накладываются на `config.php`. Сам `config.php` содержит
заглушки и в git уходит без секретов. Права на редактирование определяются
по IP клиента (`backend/api/access_control.php`), поэтому при открытии сайта
не с localhost добавьте свой адрес в `admin_ips`, иначе интерфейс будет
«Только просмотр».

### 2. PHP-API

В репозитории лежит портативный PHP 8 в `.tools/php` (папка в `.gitignore`).
Если её нет — скачайте `php-8.4-nts-Win32-vs17-x64-latest.zip` с
https://windows.php.net/download/ и распакуйте в `.tools/php`, затем включите
в `php.ini` расширения `pdo_pgsql` и `pgsql` (`extension_dir = "<путь>\ext"`).

```cmd
start-api.cmd                  :: http://127.0.0.1:8080
start-api.cmd 9000             :: другой порт (тогда поменяйте его в vite.config.js)
```

`.cmd` — основной способ запуска: он не зависит от политики выполнения
PowerShell. Альтернатива — `.\start-api.ps1`, но если система блокирует локальные
скрипты без подписи (`... не имеет цифровой подписи`, PSSecurityException),
запускайте так:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-api.ps1
```

Оба лаунчера поднимают встроенный сервер PHP с `backend/dev-router.php`, который
повторяет правила `.htaccess`: `config-endpoint.php`, `permissions.php` и
`user-info.php` отдаются напрямую, остальные `/api/...` уходят в `api/index.php`.

Проверка: http://127.0.0.1:8080/DataSources/api/permissions.php должен вернуть
`{"is_admin":true,"ip":"127.0.0.1",...}`. Если открыть его в браузере не удаётся —
значит API не запущен, и приложение покажет только данные localStorage.

### 3. Фронтенд

```powershell
npm install
npm run dev                # http://localhost:3000/DataSources/
```

Открывать нужно именно `http://localhost:3000/DataSources/`: в режиме разработки
Vite отдаёт приложение по тому же пути, что и в проде, а запросы
`/DataSources/api/*` проксирует на PHP (см. `vite.config.js`).

Если PHP-API не запущен, приложение покажет жёлтую плашку «Нет связи с PHP-API»,
в подвале будет `IP: error` и «Только просмотр», а данные — только из localStorage.
Это признак недоступного API, а не ошибки в данных.

Сборка для сервера: `npm run build` (пути в `dist/` относительные, содержимое
кладётся в корень сайта рядом с папкой `api/`).

## Запись в БД — только по кнопке

В режиме `api` правки **не** записываются в БД автоматически. Любое изменение
(добавление, редактирование, удаление, перемещение, импорт) остаётся в памяти и
сохраняется в localStorage как черновик, а в шапке появляется пометка
«Есть несохранённые изменения».

Запись в БД выполняет кнопка **«Сохранить в БД»** (доступна администраторам в режиме `api`):

- перед записью показывается подтверждение с количеством докладов/разделов и временем правок;
- запись идёт в `POST /api/import`, который **полностью заменяет** содержимое таблиц,
  поэтому в БД попадает ровно то состояние, которое видно в справочнике;
- после успешной записи черновик удаляется, пометка сменяется на «✓ Сохранено в БД»;
- при ошибке текст ошибки показывается в шапке, изменения остаются в черновике и запись можно повторить.

Кнопка **«Отменить правки»** удаляет черновик и перечитывает данные из БД.

Если вкладку закрыть или обновить с несохранёнными правками, браузер покажет
предупреждение, а сами правки восстановятся из черновика при следующем открытии
(в подсказке к пометке видно, когда они были сделаны).

Схема работы: `src/store.ts` (`saveToAPI`, `discardChangesAndReload`, `getSaveState`),
кнопка — `src/App.tsx`.

## Развёртывание (Apache)

Фронтенд — содержимое `dist/` в корень сайта (`C:/web/sites/DataSources/`),
бэкенд — папка `backend/api/` рядом с ним. Правила перезаписи:
`backend/root-htaccess.txt` (в корень сайта) и `backend/.htaccess`.
Подробности — в `backend/DEPLOYMENT.md` и `backend/SETUP_INSTRUCTIONS.txt`.
