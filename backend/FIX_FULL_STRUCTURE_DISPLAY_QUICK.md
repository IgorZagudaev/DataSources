# Краткая инструкция: Исправление отображения полной структуры

## Проблема

После редактирования элемента отображалась только изменённая часть иерархии, а не вся структура.

## Решение

Изменена функция `handleGetHierarchy()` в `backend/api/index.php` так, чтобы она возвращала ВЕСЬ доклад со всеми данными, а не только изменённую ветку.

## Установка

### 1. Загрузите обновлённые файлы

```powershell
# PHP API
copy backend\api\index.php C:\web\sites\DataSources\api\

# Фронтенд
xcopy /E /Y dist\* C:\web\sites\DataSources\
```

### 2. Перезапустите Apache

```bash
httpd -k restart
```

### 3. Очистите кэш браузера

```
Ctrl + Shift + Delete
```

## Проверка

1. Откройте приложение
2. Выберите доклад с несколькими секциями и заметками
3. Выберите любой источник
4. Нажмите "Редактировать"
5. Измените название
6. Нажмите "Сохранить"
7. ✅ **Проверьте:** Должна отобразиться вся структура доклада
