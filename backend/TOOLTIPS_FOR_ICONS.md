# Всплывающие подсказки для иконок элементов иерархии

## Описание

Добавлены всплывающие подсказки (tooltips) для иконок элементов иерархии, которые показывают название типа элемента при наведении курсора.

## Что изменилось

Теперь при наведении курсора на иконку элемента (📋, 📁, 📝, 📑, 📊, 🔀, 📚) появляется всплывающая подсказка с названием типа элемента:

- 📋 → "Доклад"
- 📁 → "Раздел доклада"
- 📝 → "Справка"
- 📑 → "Блок справки"
- 📊 → "Показатель"
- 🔀 → "Разрез данных"
- 📚 → "Источник данных"

## Реализация

### 1. Добавлена функция getTypeLabel

В файле `src/components/TreeView.tsx` добавлена функция для получения названия типа элемента:

```typescript
function getTypeLabel(type: string): string {
  const typeLabels: Record<string, string> = {
    report: 'Доклад',
    section: 'Раздел доклада',
    note: 'Справка',
    noteBlock: 'Блок справки',
    indicator: 'Показатель',
    slice: 'Разрез данных',
    source: 'Источник данных',
  };
  return typeLabels[type] || type;
}
```

### 2. Добавлен атрибут title к иконке

В компоненте `TreeNodeItem` к иконке добавлен атрибут `title`:

```typescript
{/* Icon */}
<span 
  className="text-sm flex-shrink-0"
  title={getTypeLabel(type)}
>
  {icon}
</span>
```

## Как это работает

1. Пользователь наводит курсор на иконку элемента
2. Браузер отображает стандартный tooltip с текстом из атрибута `title`
3. Текст tooltip определяется функцией `getTypeLabel(type)`

## Преимущества

1. **Улучшенная навигация** - пользователь быстро понимает тип элемента
2. **Интуитивный интерфейс** - не нужно запоминать, что означает каждая иконка
3. **Доступность** - помогает новым пользователям понять структуру
4. **Стандартное поведение** - используется нативный HTML tooltip

## Технические детали

### Атрибут title

Атрибут `title` - это стандартный HTML атрибут, который отображается как tooltip при наведении курсора. Браузеры автоматически обрабатывают этот атрибут и отображают подсказку.

### Функция getTypeLabel

Функция принимает строку `type` и возвращает соответствующее название на русском языке. Если тип не найден в словаре, возвращается исходное значение `type`.
