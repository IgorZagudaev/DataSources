# Краткая инструкция: Удаление задержки синхронизации

## ✅ Что сделано

Убрана 5-секундная задержка (debounce) перед синхронизацией. Теперь изменения отправляются на сервер **мгновенно**.

## Изменения

### Файл: `src/store.ts`

1. **Удалена переменная `syncTimeout`**
2. **Упрощена функция `notify()`** - убран `setTimeout`

## Установка

```powershell
# Загрузите обновлённые файлы
xcopy /E /Y dist\* C:\web\sites\DataSources\

# Очистите кэш браузера
# Ctrl + Shift + Delete
```

## Проверка

1. Откройте приложение
2. Откройте Network tab (F12)
3. Отредактируйте любой элемент
4. **Сразу** должен появиться запрос (без задержки 5 сек)
5. Размер: ~5-20 КБ
6. Время: ~50-200 мс

## Результат

**До:**
```
Изменение → ожидание 5 сек → отправка 5+ МБ → 2-5 сек
```

**После:**
```
Изменение → мгновенная отправка 5-20 КБ → 50-200 мс
```

## Преимущества

✅ Мгновенная синхронизация  
✅ Предсказуемое поведение  
✅ Надёжность (данные не теряются)  
✅ Проще код
