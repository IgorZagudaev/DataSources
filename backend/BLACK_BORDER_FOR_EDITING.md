# Чёрная рамка для редактируемых элементов

## Описание

Добавлена чёрная рамка для элементов, которые находятся в режиме редактирования. Теперь рамка отображается не только для выбранных элементов, но и для элементов, которые редактируются.

## Проблема

Ранее чёрная рамка отображалась только при выборе элемента (клик по названию). При нажатии на кнопку редактирования (карандаш) рамка исчезала, так как `selectedId` сбрасывался в `null` при открытии формы редактирования.

## Решение

Добавлен параметр `isEditing` для компонента `TreeNodeItem`, который отображает рамку при редактировании элемента, даже если элемент не выбран.

## Реализация

### 1. Добавлен параметр в интерфейс TreeNodeItemProps

```typescript
interface TreeNodeItemProps {
  // ... другие параметры
  isSelected: boolean;
  isEditing?: boolean;  // ← Новый параметр
  // ...
}
```

### 2. Обновлена функция TreeNodeItem

```typescript
function TreeNodeItem({
  id, name, type, level, icon, isExpanded, isSelected, isEditing = false, index = 0,
  // ... другие параметры
}: TreeNodeItemProps) {
```

### 3. Обновлено условие для отображения рамки

```typescript
<div
  className={`... ${isSelected || isEditing ? 'ring-2 ring-black ring-offset-1' : ''}`}
  // ...
>
```

### 4. Добавлена передача isEditing во все TreeNodeItem

Для всех элементов дерева добавлена передача параметра `isEditing`:

```typescript
<TreeNodeItem
  // ... другие параметры
  isSelected={selectedId === report.id}
  isEditing={editingId === report.id}  // ← Новый параметр
  // ...
/>
```

## Как это работает

### Сценарий 1: Выбор элемента
1. Пользователь кликает по названию элемента
2. Устанавливается `selectedId`
3. `isSelected = true`
4. Отображается чёрная рамка

### Сценарий 2: Редактирование элемента
1. Пользователь нажимает кнопку редактирования (карандаш)
2. Устанавливается `editingId`
3. `selectedId` сбрасывается в `null`
4. `isEditing = true`
5. Отображается чёрная рамка (благодаря `isEditing`)

### Сценарий 3: Выбор и редактирование разных элементов
1. Пользователь выбирает элемент A (`selectedId = A`)
2. Пользователь нажимает редактирование элемента B (`editingId = B`)
3. Элемент A теряет рамку (`isSelected = false`)
4. Элемент B получает рамку (`isEditing = true`)

## Обновлённые элементы

Рамка при редактировании отображается для всех типов элементов:

- ✅ Доклады (report)
- ✅ Разделы (section)
- ✅ Справки (note)
- ✅ Блоки справок (noteBlock)
- ✅ Показатели в блоках справок (noteBlockIndicator)
- ✅ Разрезы в блоках справок (noteBlockSlice)
- ✅ Источники в блоках справок (noteBlockSliceSource)
- ✅ Показатели (indicator)
- ✅ Разрезы (slice)
- ✅ Источники (source)
- ✅ Прямые источники справок (noteSource)

## Технические детали

### Параметр editingId

`editingId` передаётся в компонент `TreeView` из `App.tsx`:

```typescript
<TreeView
  reports={reports}
  selectedId={selectedId}
  editingId={formState?.editData?.id || null}  // ← Передаётся editingId
  // ...
/>
```

### Условие отображения рамки

Рамка отображается, если:
- `isSelected === true` (элемент выбран) **ИЛИ**
- `isEditing === true` (элемент редактируется)

```typescript
${isSelected || isEditing ? 'ring-2 ring-black ring-offset-1' : ''}
```

## Преимущества

1. **Постоянная визуальная индикация** - рамка отображается как при выборе, так и при редактировании
2. **Улучшенный UX** - пользователь всегда видит, с каким элементом работает
3. **Независимость от selectedId** - рамка не исчезает при открытии формы редактирования
4. **Совместимость с существующей логикой** - не требует изменения логики выбора/редактирования
