# Краткая инструкция: Система контроля доступа по IP

## Что добавлено

✅ **Контроль доступа по IP-адресам** для административных функций  
✅ **Двухуровневая защита**: frontend (скрытие кнопок) + backend (проверка прав)  
✅ **Отображение статуса** в футере: "Администратор" или "Только просмотр"  
✅ **Логирование** попыток несанкционированного доступа

## Настройка

### 1. Откройте config.php

```
C:\web\sites\DataSources\api\config.php
```

### 2. Добавьте IP-адреса администраторов

```php
'admin_ips' => [
    '127.0.0.1',           // localhost
    '::1',                 // localhost IPv6
    '10.64.8.68',          // Ваш IP-адрес
    // Добавьте сюда IP-адреса администраторов
],
```

### 3. Сохраните файл

## Установка

### Загрузите файлы на сервер

```powershell
# Backend
copy backend\api\config.php C:\web\sites\DataSources\api\
copy backend\api\access_control.php C:\web\sites\DataSources\api\
copy backend\api\permissions.php C:\web\sites\DataSources\api\
copy backend\api\index.php C:\web\sites\DataSources\api\
copy backend\.htaccess C:\web\sites\DataSources\

# Frontend
xcopy /E /Y dist\* C:\web\sites\DataSources\
```

### Перезапустите Apache

```bash
httpd -k restart
```

## Проверка

### 1. Проверьте свои права

Откройте в браузере:
```
http://ваш_сервер/DataSources/api/permissions.php
```

Ожидаемый ответ:
```json
{
  "is_admin": true,
  "ip": "10.64.8.68",
  "can_edit": true,
  "can_import": true,
  "can_export": true,
  "can_delete": true
}
```

### 2. Проверьте UI

1. Откройте приложение
2. В футере должен появиться значок "Администратор" (зелёный)
3. Должны быть видны кнопки: Экспорт, Импорт, Сброс
4. В дереве должны быть видны кнопки действий: +, ✎, ✕, ↑, ↓

### 3. Проверьте с другого IP

1. Откройте приложение с другого IP (не из списка администраторов)
2. В футере должен появиться значок "Только просмотр" (серый)
3. Кнопки административных функций должны быть скрыты
4. Кнопки действий в дереве должны быть скрыты

## Решение проблем

### Проблема: Администратор не имеет прав

**Решение:**
1. Проверьте, что IP-адрес добавлен в `admin_ips`
2. Проверьте, как определяется IP:
   ```
   http://ваш_сервер/DataSources/api/permissions.php
   ```
3. Если IP определяется неправильно (за прокси), добавьте правильный IP в список

### Проблема: Кнопки всё ещё видны

**Решение:**
1. Очистите кэш браузера (Ctrl+Shift+Delete)
2. Перезагрузите страницу (Ctrl+F5)
3. Проверьте консоль браузера на ошибки

### Проблема: Ошибка 403

**Решение:**
1. Проверьте, что IP-адрес добавлен в `admin_ips`
2. Проверьте логи PHP
3. Проверьте, что файл `access_control.php` загружен
