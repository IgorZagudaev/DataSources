# Исправление цвета шрифта в модальном окне загрузки

## Проблема

Пользователь попросил изменить цвет шрифта в модальном окне загрузки с белого на чёрный.

## Решение

Изменена цветовая схема модального окна загрузки в `src/App.tsx`:

### Изменения:

1. **Фон окна**: `bg-gray-900` → `bg-white` (белый фон)
2. **Граница**: `border-gray-600` → `border-gray-300` (светлее для контраста)
3. **Заголовок**: `#ffffff` → `#000000` (чёрный текст)
4. **Подзаголовок**: `#e5e7eb` → `#374151` (тёмно-серый для читаемости)
5. **Спиннер**: `border-blue-400` → `border-blue-600` (ярче для видимости на белом фоне)
6. **Оверлей**: `transparent` → `rgba(0, 0, 0, 0.3)` (лёгкое затемнение страницы)

## Результат

Теперь модальное окно загрузки:
- ✅ По центру экрана
- ✅ Белый фон окна
- ✅ Чёрный текст (гарантированно читаемый)
- ✅ Лёгкое затемнение страницы (30% непрозрачности)
- ✅ Яркий синий спиннер для видимости
