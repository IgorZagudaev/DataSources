# Добавление отступа в футере между IP-адресом и статистикой

## Проблема

В футере приложения между блоком IP-адреса (с бейджем администратора/только просмотр) и статистикой (Докладов: X | Разделов: Y) отсутствовал достаточный визуальный отступ.

## Решение

Добавлен дополнительный отступ `ml-4` (margin-left: 1rem / 16px) к элементу со статистикой.

## Изменения

### Файл: `src/App.tsx`

**Строка 765:**

**Было:**
```tsx
<span>Докладов: {reports.length} | Разделов: {reports.reduce((sum, r) => sum + r.sections.length, 0)}</span>
```

**Стало:**
```tsx
<span className="ml-4">Докладов: {reports.length} | Разделов: {reports.reduce((sum, r) => sum + r.sections.length, 0)}</span>
```

## Визуальный результат

**До:**
```
Apache + PHP 8 + PostgreSQL | Справочник источников данных показателей    IP: 10.64.8.68 [Администратор]Докладов: 5 | Разделов: 12
```

**После:**
```
Apache + PHP 8 + PostgreSQL | Справочник источников данных показателей    IP: 10.64.8.68 [Администратор]    Докладов: 5 | Разделов: 12
```

## Технические детали

- **Отступ:** `ml-4` (Tailwind CSS) = `margin-left: 1rem` = `16px`
- **Дополнительный отступ:** Родительский div уже имеет `gap-4`, но этого было недостаточно для визуального разделения
- **Адаптивность:** Отступ работает на всех размерах экрана
