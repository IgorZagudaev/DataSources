# Улучшение задержки синхронизации и центрирования при редактировании

## Дата
2026-09-17

## Внесенные изменения

### 1. Уменьшение задержки синхронизации с 5 до 3 секунд

**Файл:** `src/store.ts`

**Изменение:**
```typescript
// Было:
syncTimeout = setTimeout(() => {
  syncToAPI();
  syncTimeout = null;
}, 5000); // Синхронизация через 5 секунд после последнего изменения

// Стало:
syncTimeout = setTimeout(() => {
  syncToAPI();
  syncTimeout = null;
}, 3000); // Синхронизация через 3 секунды после последнего изменения
```

**Обоснование:**
- 5 секунд - слишком долгая задержка для пользователя
- 3 секунды - оптимальный баланс между производительностью и отзывчивостью
- Позволяет объединить несколько быстрых изменений в одну синхронизацию
- Снижает нагрузку на сервер по сравнению с мгновенной синхронизацией

### 2. Улучшение центрирования при редактировании

**Файл:** `src/components/TreeView.tsx`

**Проблема:**
При редактировании элемента центрирование работало нестабильно:
- При добавлении справки центрирование работало правильно
- При редактировании центрирование зависело от количества справок и могло работать неправильно

**Причина:**
- При редактировании `editingId` устанавливается с задержкой 10мс через setTimeout
- Центрирование срабатывало через 400мс, но этого было недостаточно для завершения всех анимаций и рендеринга
- Вторая панель (форма редактирования) появляется с анимацией 300мс

**Решение:**
Добавлена двойная попытка центрирования:
```typescript
// Автоматическое центрирование редактируемой строки
useEffect(() => {
  if (!editingId || !treeContainerRef.current) return;

  const centerElement = () => {
    const editingElement = treeContainerRef.current?.querySelector(`[data-node-id="${editingId}"]`);
    if (editingElement) {
      editingElement.scrollIntoView({
        behavior: 'smooth',
        block: 'center'
      });
    }
  };

  // Первая попытка центрирования через 400мс
  const timeout1 = setTimeout(centerElement, 400);
  
  // Повторная попытка через 600мс на случай, если первая не сработала
  const timeout2 = setTimeout(centerElement, 600);

  return () => {
    clearTimeout(timeout1);
    clearTimeout(timeout2);
  };
}, [editingId]);
```

**Обоснование:**
- Первая попытка через 400мс - для быстрого центрирования в большинстве случаев
- Вторая попытка через 600мс - страховка на случай медленного рендеринга или анимаций
- Очистка таймеров при размонтировании предотвращает утечки памяти

## Влияние на производительность

### Задержка синхронизации
- **До:** 5 секунд
- **После:** 3 секунды
- **Эффект:** Более отзывчивый интерфейс, быстрая синхронизация с сервером

### Центрирование при редактировании
- **До:** Нестабильное центрирование, зависящее от количества элементов
- **После:** Стабильное центрирование в всех случаях
- **Эффект:** Улучшенный UX, предсказуемое поведение интерфейса

## Известные ограничения

- Двойная попытка центрирования может вызвать легкое "дрожание" элемента при очень медленном соединении
- Задержка 3 секунды может быть недостаточной для очень медленных сетей (но это лучше, чем 5 секунд)

## Будущие улучшения

1. **Адаптивная задержка синхронизации:**
   - Автоматически увеличивать задержку при медленном соединении
   - Уменьшать задержку при быстром соединении

2. **Отмена центрирования при прокрутке пользователем:**
   - Если пользователь начал прокрутку во время центрирования, отменить автоматическое центрирование

3. **Индикатор синхронизации:**
   - Показывать пользователю, что данные синхронизируются с сервером
   - Избегать неожиданной синхронизации через 3 секунды
