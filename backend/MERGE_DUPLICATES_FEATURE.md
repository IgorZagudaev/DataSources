# Объединение докладов при импорте

## Описание функции

При импорте данных можно выбрать режим объединения докладов с одинаковыми названиями. Если чекбокс включен, то вместо создания дубликатов новые разделы добавляются в существующие доклады с тем же названием.

## Как это работает

### Режим выключен (по умолчанию)
- Каждый импортированный доклад создается как новый
- Даже если доклад с таким названием уже существует
- Результат: могут появиться дубликаты докладов

### Режим включен
- При импорте проверяется, есть ли уже доклад с таким названием
- Если есть - новые разделы добавляются в существующий доклад
- Если нет - создается новый доклад
- Результат: нет дубликатов, данные объединяются

## Использование

1. Откройте модальное окно импорта (кнопка "Импорт" в шапке)
2. Вставьте JSON данные в textarea
3. **Установите чекбокс "Объединять доклады с одинаковыми названиями"**
4. Нажмите кнопку "Импортировать"

## Пример

### Исходные данные в БД:
```
Доклад "Социально-экономическое развитие 2024"
├── Раздел "Демография"
│   └── Справка "Численность населения"
```

### Импортируемые данные:
```json
{
  "reports": [
    {
      "name": "Социально-экономическое развитие 2024",
      "sections": [
        {
          "name": "Экономика",
          "notes": [
            {
              "name": "ВРП",
              "indicators": [...]
            }
          ]
        }
      ]
    }
  ]
}
```

### Результат с включенным объединением:
```
Доклад "Социально-экономическое развитие 2024"
├── Раздел "Демография"
│   └── Справка "Численность населения"
└── Раздел "Экономика"          ← Добавлен из импорта
    └── Справка "ВРП"
```

### Результат с выключенным объединением:
```
Доклад "Социально-экономическое развитие 2024"
├── Раздел "Демография"
│   └── Справка "Численность населения"

Доклад "Социально-экономическое развитие 2024"  ← Дубликат!
└── Раздел "Экономика"
    └── Справка "ВРП"
```

## Технические детали

### Изменения в UI (App.tsx)

1. **Добавлено состояние**:
```typescript
const [mergeDuplicates, setMergeDuplicates] = useState(false);
```

2. **Добавлен чекбокс**:
```tsx
<div className="flex items-center gap-2 p-2 bg-blue-50 rounded-lg">
  <input
    type="checkbox"
    id="mergeDuplicates"
    checked={mergeDuplicates}
    onChange={(e) => setMergeDuplicates(e.target.checked)}
    className="w-4 h-4 text-blue-600 border-gray-300 rounded focus:ring-blue-500"
  />
  <label htmlFor="mergeDuplicates" className="text-sm text-gray-700 cursor-pointer">
    Объединять доклады с одинаковыми названиями
  </label>
</div>
```

3. **Передача параметра в importData**:
```typescript
const success = importData(currentText, mergeDuplicates);
```

### Изменения в логике (store.ts)

Функция `importData` теперь принимает второй параметр:

```typescript
export function importData(json: string, mergeDuplicates: boolean = false): boolean
```

**Логика работы:**

1. Если `mergeDuplicates === false`:
   - Создает новые доклады как обычно
   - Генерирует новые ID для всех элементов

2. Если `mergeDuplicates === true`:
   - Для каждого импортируемого доклада:
     - Ищет существующий доклад с таким же названием
     - Если найден:
       - Генерирует новые ID для разделов и вложенных элементов
       - Добавляет новые разделы в существующий доклад
     - Если не найден:
       - Создает новый доклад как обычно

## Преимущества

1. **Избежание дубликатов**: Не создает копии докладов с одинаковыми названиями
2. **Дополнение данных**: Позволяет добавлять новые разделы к существующим докладам
3. **Гибкость**: Пользователь сам выбирает режим импорта
4. **Безопасность**: Существующие данные не удаляются, только добавляются новые

## Когда использовать

### Включайте объединение, когда:
- Импортируете дополнительные разделы к существующему докладу
- Обновляете доклад новыми данными
- Избегаете дублирования структуры

### Выключайте объединение, когда:
- Импортируете полностью новые доклады
- Хотите создать копию доклада
- Тестируете импорт данных

## Решение проблем

### Проблема: Объединение не работает
**Решение:** Убедитесь, что:
1. Чекбокс установлен
2. Названия докладов совпадают точно (с учетом пробелов и регистра)
3. JSON валидный

### Проблема: Разделы не добавляются
**Решение:** Проверьте:
1. Структуру JSON данных
2. Логи в консоли браузера (F12)
3. Что существующий доклад действительно есть в БД

### Проблема: Создается дубликат вместо объединения
**Решение:** Убедитесь, что:
1. Чекбокс "Объединять доклады с одинаковыми названиями" установлен
2. Названия докладов идентичны (проверьте пробелы, регистр)

## Логи в консоли

При включенном объединении в консоли будут сообщения:
```
Режим объединения дубликатов включен
Найден существующий доклад "Название доклада", добавляем разделы
```

или

```
Доклад "Название доклада" не найден, создаем новый
```

## Ограничения

1. **Сравнение по точному совпадению**: Названия должны совпадать полностью (с учетом регистра и пробелов)
2. **Объединение только на уровне докладов**: Разделы, справки и другие элементы всегда создаются как новые
3. **Нет проверки дубликатов разделов**: Если раздел с таким названием уже есть, будет создан еще один

## Будущие улучшения

Возможные доработки:
1. Объединение на уровне разделов (если название раздела совпадает)
2. Нечеткое сравнение названий (игнорирование регистра, пробелов)
3. Визуальное отображение, какие доклады будут объединены
4. Предпросмотр изменений перед импортом
5. Отмена объединения для конкретных докладов
