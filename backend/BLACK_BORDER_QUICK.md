# Краткая инструкция: Чёрная рамка для действий добавления и удаления

## Что добавлено

Чёрная рамка теперь отображается при:
- ✅ Выборе элемента (клик по названию)
- ✅ Редактировании элемента (нажатие на карандаш)
- ✅ Добавлении дочернего элемента (нажатие на "+")
- ✅ Удалении элемента (нажатие на "✕")

## Как это работает

### При добавлении дочернего элемента
- Подсвечивается родительский элемент (тот, к которому добавляется дочерний)
- Пример: нажали "+" на "Раздел 1" → рамка вокруг "Раздел 1"

### При удалении элемента
- Подсвечивается удаляемый элемент
- Пример: нажали "✕" на "Справка 1" → рамка вокруг "Справка 1"

## Изменения в коде

### App.tsx
- Добавлено состояние `actionId` для отслеживания элемента действия
- `handleAdd` - устанавливает `actionId` на родительский элемент
- `handleDelete` - устанавливает `actionId` на удаляемый элемент
- `handleSelect`, `handleEdit`, `handleCloseDetail` - сбрасывают `actionId`

### TreeView.tsx
- Добавлен параметр `actionId` в `TreeViewProps`
- Добавлен параметр `isAction` в `TreeNodeItemProps`
- Обновлено условие для рамки: `isSelected || isEditing || isAction`
- Добавлена передача `isAction={actionId === id}` всем элементам

## Обновление

Загрузите обновлённые файлы из папки `dist/` на сервер:

```
dist/* → C:/web/sites/DataSources/
```

## Проверка

1. Откройте приложение
2. Нажмите "+" на любом элементе → должна появиться рамка вокруг родителя
3. Нажмите "✕" на любом элементе → должна появиться рамка вокруг удаляемого элемента
4. Закройте форму/диалог → рамка должна исчезнуть
