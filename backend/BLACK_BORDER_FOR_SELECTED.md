# Чёрная рамка для выбранных элементов

## Описание

Добавлена визуальная индикация выбранных элементов в дереве иерархии - чёрная рамка вокруг элемента.

## Как это работает

Когда пользователь выбирает элемент в дереве (клик по названию элемента), вокруг него появляется чёрная рамка толщиной 2px с отступом 1px от элемента.

## Реализация

### Изменения в коде

В файле `src/components/TreeView.tsx` в компоненте `TreeNodeItem` добавлено условное применение CSS классов:

```tsx
<div
  className={`flex items-center gap-1 py-1.5 px-2 rounded-lg cursor-pointer transition-all border-l-4 hover:opacity-80 ${isSelected ? 'ring-2 ring-black ring-offset-1' : ''}`}
  style={{ 
    paddingLeft: `${level * 16 + 8}px`,
    backgroundColor: bgColor,
    borderLeftColor: borderColor
  }}
>
```

### Используемые CSS классы

- `ring-2` - создаёт рамку толщиной 2px
- `ring-black` - цвет рамки чёрный
- `ring-offset-1` - отступ рамки от элемента 1px

## Визуальный эффект

### До выбора
Элемент имеет цветной фон и левую цветную границу, соответствующую типу элемента.

### После выбора
Элемент дополнительно получает:
- Чёрную рамку толщиной 2px вокруг всего элемента
- Отступ 1px между элементом и рамкой
- Сохраняет цветной фон и левую границу

## Преимущества

1. **Чёткая визуальная индикация** - сразу видно, какой элемент выбран
2. **Не перекрывает содержимое** - рамка добавляется снаружи элемента
3. **Совместимость с цветовой схемой** - не конфликтует с цветными фонами уровней
4. **Плавная анимация** - transition-all обеспечивает плавное появление рамки

## Тестирование

### Проверка работы

1. Откройте приложение
2. Кликните по любому элементу в дереве
3. Убедитесь, что вокруг элемента появилась чёрная рамка
4. Кликните по другому элементу
5. Убедитесь, что рамка переместилась на новый элемент

### Ожидаемое поведение

- Рамка появляется только вокруг выбранного элемента
- При выборе другого элемента рамка перемещается
- Рамка не перекрывает текст и иконки элемента
- Рамка видна на всех уровнях иерархии

## Применение

Рамка применяется ко всем типам элементов:
- 📋 Доклады (report)
- 📁 Разделы (section)
- 📝 Справки (note)
- 📑 Блоки справок (noteBlock)
- 📊 Показатели (indicator)
- 🔀 Разрезы (slice)
- 📚 Источники (source)

## Технические детали

### CSS Ring Utility

Tailwind CSS использует `ring` utility для создания рамок:

```css
.ring-2 {
  --tw-ring-offset-shadow: var(--tw-ring-inset) 0 0 0 var(--tw-ring-offset-width) var(--tw-ring-offset-color);
  --tw-ring-shadow: var(--tw-ring-inset) 0 0 0 calc(2px + var(--tw-ring-offset-width)) var(--tw-ring-color);
  box-shadow: var(--tw-ring-offset-shadow), var(--tw-ring-shadow), var(--tw-shadow, 0 0 #0000);
}

.ring-black {
  --tw-ring-opacity: 1;
  --tw-ring-color: rgb(0 0 0 / var(--tw-ring-opacity));
}

.ring-offset-1 {
  --tw-ring-offset-width: 1px;
}
```

### Альтернативные варианты

Если нужно изменить стиль рамки, можно использовать:

```tsx
// Более толстая рамка
className={isSelected ? 'ring-4 ring-black ring-offset-2' : ''}

// Цветная рамка
className={isSelected ? 'ring-2 ring-blue-500 ring-offset-1' : ''}

// Пунктирная рамка (требует дополнительного CSS)
className={isSelected ? 'border-2 border-dashed border-black' : ''}
```
