# Исправление проблемы с центрированием при выборе/редактировании элементов

## Проблема

При выборе или редактировании Раздела (или любого другого элемента с большим количеством дочерних элементов) центрирование работало некорректно:
- Центрировалась не сама строка элемента, а вся область с дочерними элементами
- При большом количестве справок раздел оказывался выше видимой области
- Пользователь не видел выбранный элемент после центрирования

## Причина

Атрибут `data-node-id` был установлен на родительский контейнер, который включал:
- Строку элемента (название, иконка, кнопки)
- Все дочерние элементы (справки, показатели, разрезы и т.д.)

Когда вызывался `scrollIntoView()` на этом контейнере, браузер центрировал всю область с дочерними элементами, а не только строку элемента.

### Пример проблемы:

```
┌─────────────────────────────────────┐
│ 📁 Раздел 1 (data-node-id здесь)    │ ← Строка элемента
├─────────────────────────────────────┤
│ 📝 Справка 1                        │
│ 📝 Справка 2                        │
│ 📝 Справка 3                        │ ← Дочерние элементы
│ ...                                 │
│ 📝 Справка 50                       │
└─────────────────────────────────────┘
       ↑ Вся эта область центрировалась
```

## Решение

Переместить атрибут `data-node-id` с родительского контейнера на саму строку элемента.

### До исправления:

```tsx
return (
  <div className={`select-none ${type === 'report' ? 'my-6' : ''}`} data-node-id={id}>
    <div
      className={`flex items-center gap-1 py-1.5 px-2 rounded-lg ...`}
      style={{ ... }}
    >
      {/* Строка элемента */}
    </div>
    
    {/* Дочерние элементы */}
    {children}
  </div>
);
```

### После исправления:

```tsx
return (
  <div className={`select-none ${type === 'report' ? 'my-6' : ''}`}>
    <div
      data-node-id={id}  // ← Атрибут перемещён сюда
      className={`flex items-center gap-1 py-1.5 px-2 rounded-lg ...`}
      style={{ ... }}
    >
      {/* Строка элемента */}
    </div>
    
    {/* Дочерние элементы */}
    {children}
  </div>
);
```

## Как это работает

### Пример исправления:

```
┌─────────────────────────────────────┐
│ 📁 Раздел 1                         │
├─────────────────────────────────────┤ ← data-node-id здесь
│ 📝 Справка 1                        │
│ 📝 Справка 2                        │
│ 📝 Справка 3                        │
│ ...                                 │
│ 📝 Справка 50                       │
└─────────────────────────────────────┘
       ↑ Только эта строка центрируется
```

Теперь `scrollIntoView()` центрирует только строку элемента (название, иконка, кнопки), а не всю область с дочерними элементами.

## Решение проблем

### Проблема: Центрирование всё ещё работает неправильно

**Решение:**
1. Проверьте, что загружен обновлённый `TreeView.tsx`
2. Очистите кэш браузера (Ctrl + Shift + Delete)
3. Перезагрузите страницу (Ctrl + F5)
4. Проверьте консоль браузера на наличие ошибок

### Проблема: Атрибут data-node-id не найден

**Решение:**
1. Откройте консоль браузера (F12)
2. Выполните:
   ```javascript
   document.querySelector('[data-node-id]')
   ```
3. Должен вернуться элемент строки (div с flex), а не родительский контейнер

## Преимущества исправления

✅ **Точное центрирование** - центрируется только строка элемента  
✅ **Независимость от дочерних элементов** - количество справок/показателей не влияет  
✅ **Улучшенный UX** - пользователь всегда видит выбранный элемент  
✅ **Работает для всех уровней** - доклады, разделы, справки, блоки, показатели, разрезы, источники
