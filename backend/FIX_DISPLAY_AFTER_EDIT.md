# Исправление проблемы с отображением данных после редактирования

## Проблема

После редактирования элемента отображалась только изменённая часть иерархии, а не вся структура. Например, при редактировании источника показывался только этот источник, а не весь доклад со всеми разделами, справками и показателями.

## Причина

Проблема была в функции `updateLocalState()`, которая неправильно сливала данные из иерархии с существующим состоянием. Функции слияния (`mergeHierarchy`, `mergeSection`, `mergeNote`, `mergeIndicator`, `mergeSlice`) не сохраняли все данные из существующего состояния.

### Конкретные проблемы:

1. **`updateLocalState()`** - использовала `map()` для замены докладов, но не сохраняла данные других докладов
2. **`mergeHierarchy()`** - не правильно сливала секции
3. **`mergeSection()`** - не сохраняла все заметки
4. **`mergeNote()`** - не сохраняла все индикаторы и источники
5. **`mergeIndicator()`** - не сохраняла все срезы
6. **`mergeSlice()`** - не сохраняла все источники

## Решение

### 1. Улучшенная функция `updateLocalState()`

```typescript
function updateLocalState(currentReports: any[], hierarchy: any): any[] {
  if (!hierarchy || !hierarchy.id) {
    return currentReports;
  }
  
  // Находим индекс изменённого доклада
  const reportIndex = currentReports.findIndex(r => r.id === hierarchy.id);
  
  if (reportIndex === -1) {
    // Если доклад не найден, добавляем его
    return [...currentReports, hierarchy];
  }
  
  // Создаём новую копию массива
  const newReports = [...currentReports];
  
  // Обновляем только изменённый доклад
  newReports[reportIndex] = deepMerge(currentReports[reportIndex], hierarchy);
  
  return newReports;
}
```

**Ключевые изменения:**
- Находим индекс доклада вместо `map()`
- Создаём новую копию массива
- Используем `deepMerge()` для глубокого слияния

### 2. Универсальная функция `deepMerge()`

```typescript
function deepMerge(target: any, source: any): any {
  if (!source) return target;
  if (!target) return source;
  
  const result = { ...target };
  
  for (const key in source) {
    if (source.hasOwnProperty(key)) {
      if (Array.isArray(source[key])) {
        // Для массивов - заменяем полностью
        result[key] = source[key];
      } else if (typeof source[key] === 'object' && source[key] !== null) {
        // Для объектов - рекурсивное слияние
        result[key] = deepMerge(target[key] || {}, source[key]);
      } else {
        // Для примитивов - заменяем
        result[key] = source[key];
      }
    }
  }
  
  return result;
}
```

**Преимущества:**
- Универсальная функция для слияния любых объектов
- Рекурсивное слияние для вложенных объектов
- Полная замена массивов (чтобы не было дубликатов)
- Замена примитивных значений

### 3. Улучшенные функции слияния

Все функции слияния (`mergeHierarchy`, `mergeSection`, `mergeNote`, `mergeIndicator`, `mergeSlice`) были улучшены:

```typescript
function mergeSection(existingSection: any, newSection: any): any {
  if (!newSection) return existingSection;
  if (!existingSection) return newSection;
  
  const merged = { ...existingSection, ...newSection };
  
  if (newSection.notes) {
    merged.notes = newSection.notes.map((newNote: any) => {
      const existingNote = existingSection.notes?.find((n: any) => n.id === newNote.id);
      return mergeNote(existingNote || {}, newNote);
    });
  }
  
  return merged;
}
```

**Ключевые изменения:**
- Проверка на `null` и `undefined`
- Слияние базовых свойств через spread operator
- Рекурсивное слияние вложенных массивов
- Сохранение всех данных из существующего состояния

## Как это работает

### Пример: Редактирование источника

**До исправления:**
```
1. Пользователь редактирует источник
2. API возвращает только ветку: source → slice → indicator → note → section → report
3. updateLocalState() заменяет весь доклад на эту ветку
4. Результат: отображается только этот источник, остальные данные потеряны
```

**После исправления:**
```
1. Пользователь редактирует источник
2. API возвращает ветку: source → slice → indicator → note → section → report
3. updateLocalState() находит доклад по ID
4. deepMerge() сливает новые данные с существующими:
   - Сохраняет все секции из существующего доклада
   - Обновляет только изменённую секцию
   - Сохраняет все заметки в секции
   - Обновляет только изменённую заметку
   - Сохраняет все индикаторы в заметке
   - Обновляет только изменённый индикатор
   - Сохраняет все срезы в индикаторе
   - Обновляет только изменённый срез
   - Сохраняет все источники в срезе
   - Обновляет только изменённый источник
5. Результат: отображается вся структура с обновлённым источником
```
