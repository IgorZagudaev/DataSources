# Инструкция по использованию гибридного режима

## Переключение между режимами

В шапке приложения есть переключатель режимов:
- **Локальный** - данные хранятся в localStorage браузера
- **PostgreSQL** - данные хранятся в базе данных PostgreSQL

## Режим "Локальный"

- Данные хранятся в браузере пользователя
- Работает быстро, без задержек сети
- Данные теряются при очистке браузера
- Подходит для тестирования и демо

## Режим "PostgreSQL"

- Данные хранятся в базе данных PostgreSQL
- Доступны с любого устройства
- Сохраняются между сессиями
- Подходит для продакшена

### Как работает синхронизация

1. **При загрузке страницы** - данные загружаются из PostgreSQL
2. **При любом изменении** - изменения сохраняются локально И отправляются на сервер
3. **Импорт данных** - данные импортируются локально И отправляются на сервер

### Обновление PHP API

Загрузите обновлённый файл `backend/api/index.php` на сервер:
```
C:/web/sites/DataSources/api/index.php
```

Этот файл включает:
- Все CRUD операции для всех уровней иерархии
- Endpoint `/import` для массового импорта данных
- Автоматическую синхронизацию при каждом изменении

### Тестирование

1. Откройте сайт: `http://10.64.8.68/DataSources/`
2. Нажмите кнопку **"PostgreSQL"** в шапке
3. Данные должны загрузиться из базы данных
4. Добавьте новый доклад - он появится в дереве И сохранится в БД
5. Обновите страницу - данные должны остаться
6. Переключитесь в режим **"Локальный"** - данные из localStorage
7. Переключитесь обратно в **"PostgreSQL"** - данные из БД

### Проверка в базе данных

Выполните SQL запрос для проверки:
```sql
SELECT * FROM reports ORDER BY created_at DESC LIMIT 5;
```

### Решение проблем

**Данные не загружаются из БД:**
- Проверьте, что PHP API доступен: `http://10.64.8.68/DataSources/api/reports`
- Проверьте логи Apache: `C:/web/Apache24/logs/error.log`
- Проверьте подключение к БД в `config.php`

**Данные не сохраняются в БД:**
- Откройте консоль браузера (F12)
- Проверьте вкладку Network - должны быть POST запросы к `/DataSources/api/import`
- Проверьте ответ сервера - должен быть `{"success":true}`

**Ошибки при импорте:**
- Убедитесь, что JSON валидный
- Проверьте структуру данных (должна соответствовать иерархии)
- Проверьте логи PHP и PostgreSQL

## Архитектура

```
┌─────────────────┐
│   React App     │
│  (Frontend)     │
└────────┬────────┘
         │
         ├─[Локальный режим]──► localStorage
         │
         └─[PostgreSQL режим]──► PHP API ──► PostgreSQL
                                      │
                                      └─► /api/import (bulk sync)
```

## Производительность

- **Локальный режим**: мгновенный отклик, нет сетевых задержек
- **PostgreSQL режим**: 
  - Чтение: ~100-500ms (зависит от сети)
  - Запись: асинхронная, не блокирует UI
  - Синхронизация: автоматическая при каждом изменении

## Безопасность

- API не требует аутентификации (добавьте позже для продакшена)
- Данные передаются по HTTP (используйте HTTPS для продакшена)
- Нет валидации данных на сервере (добавьте позже)

## Следующие шаги (опционально)

1. **Аутентификация** - добавить JWT или session-based auth
2. **HTTPS** - настроить SSL сертификат
3. **Валидация** - добавить проверку данных на сервере
4. **Кэширование** - добавить Redis для ускорения чтения
5. **Резервное копирование** - настроить автоматический бэкап БД
6. **Логирование** - добавить логирование всех операций

3. Проверьте доступность API: `http://10.64.8.68/DataSources/api/reports`
