# Краткая инструкция: Исправление отображения данных после редактирования

## Проблема

После редактирования элемента отображалась только изменённая часть иерархии, а не вся структура.

## Решение

Исправлены функции слияния данных в `src/store.ts`:

### Изменённые функции:

1. **`updateLocalState()`** - улучшена логика обновления состояния
2. **`deepMerge()`** - добавлена универсальная функция глубокого слияния
3. **`mergeHierarchy()`** - улучшено слияние докладов
4. **`mergeSection()`** - улучшено слияние разделов
5. **`mergeNote()`** - улучшено слияние заметок
6. **`mergeIndicator()`** - улучшено слияние индикаторов
7. **`mergeSlice()`** - улучшено слияние срезов

## Проверка

### Тест 1: Редактирование источника

1. Выберите любой источник
2. Нажмите "Редактировать"
3. Измените название
4. Нажмите "Сохранить"
5. ✅ **Проверьте:** Должна отобразиться вся структура доклада

### Тест 2: Добавление элемента

1. Выберите раздел
2. Нажмите "+" для добавления заметки
3. Заполните форму
4. Нажмите "Сохранить"
5. ✅ **Проверьте:** Должна отобразиться вся структура с новой заметкой

### Тест 3: Удаление элемента

1. Выберите любой элемент
2. Нажмите "Удалить"
3. Подтвердите удаление
4. ✅ **Проверьте:** Должна отобразиться вся структура без удалённого элемента

## Результат

✅ При редактировании отображается вся структура  
✅ При добавлении сохраняются все существующие данные  
✅ При удалении сохраняется остальная структура  
✅ При перемещении отображается вся структура с новым порядком
