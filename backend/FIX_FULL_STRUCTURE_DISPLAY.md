# Исправление проблемы с отображением полной структуры после редактирования

## Проблема

После редактирования элемента отображалась только изменённая часть иерархии, а не вся структура. Например:
- При редактировании источника показывался только этот источник
- При редактировании заметки показывалась только эта заметка
- Остальные элементы доклада не отображались

## Причина

Функция `handleGetHierarchy()` в `backend/api/index.php` возвращала только изменённую ветку иерархии, а не весь доклад.

### Пример проблемы (до исправления):

```php
case 'sources':
    $source = getSource($db, $id);
    $slice = getSlice($db, $source['slice_id']);
    $indicator = getIndicator($db, $slice['indicator_id']);
    $note = getNote($db, $indicator['note_id']);
    $section = getSection($db, $note['section_id']);
    $report = getReport($db, $section['report_id']);
    
    // ❌ ПРОБЛЕМА: Возвращается только один источник, один срез, один индикатор и т.д.
    $slice['sources'] = [$source];
    $indicator['slices'] = [$slice];
    $note['indicators'] = [$indicator];
    $section['notes'] = [$note];
    $report['sections'] = [$section];
    
    echo json_encode($report);
    return;
```

**Результат:** API возвращает только одну ветку иерархии, а не весь доклад со всеми секциями, заметками, индикаторами и т.д.

## Решение

Изменены все случаи в функции `handleGetHierarchy()` так, чтобы они использовали функции `getReportWithChildren()`, `getSectionWithChildren()`, `getNoteWithChildren()` и т.д., которые загружают ВСЕ дочерние элементы.

### Исправленный код:

```php
case 'sources':
    $source = getSource($db, $id);
    $slice = getSliceWithChildren($db, $source['slice_id']);
    $indicator = getIndicatorWithChildren($db, $slice['indicator_id']);
    $note = getNoteWithChildren($db, $indicator['note_id']);
    $section = getSectionWithChildren($db, $note['section_id']);
    $report = getReportWithChildren($db, $section['report_id']);
    
    // ✅ ИСПРАВЛЕНО: Возвращается весь доклад со всеми данными
    echo json_encode($report);
    return;
```

**Результат:** API возвращает весь доклад со всеми секциями, заметками, индикаторами, срезами и источниками.

## Как это работает

### Пример: Редактирование источника

**До исправления:**
```
1. Пользователь редактирует источник
2. API возвращает: report → section → note → indicator → slice → source
   (только одна ветка иерархии)
3. Фронтенд получает только этот источник
4. ❌ Результат: отображается только этот источник
```

**После исправления:**
```
1. Пользователь редактирует источник
2. API возвращает: report → [все sections] → [все notes] → [все indicators] → [все slices] → [все sources]
   (весь доклад со всеми данными)
3. Фронтенд получает весь доклад
4. ✅ Результат: отображается вся структура с обновлённым источником
```

## Решение проблем

### Проблема: Данные всё ещё не отображаются полностью

**Решение:**
1. Проверьте, что загружен обновлённый `index.php`
2. Проверьте, что загружены обновлённые файлы из `dist/`
3. Очистите кэш браузера (Ctrl + Shift + Delete)
4. Перезапустите Apache
5. Проверьте логи PHP на наличие ошибок

### Проблема: Медленная загрузка

**Решение:**
1. Проверьте объём данных в базе
2. Оптимизируйте индексы в PostgreSQL
3. Проверьте производительность сервера
4. Рассмотрите кэширование на стороне клиента

### Проблема: Ошибки в консоли браузера

**Решение:**
1. Откройте консоль браузера (F12)
2. Проверьте ошибки в Console tab
3. Проверьте Network tab на наличие ошибок API
4. Проверьте логи PHP в `C:/web/Apache24/logs/error.log`
