# Добавление проверки IP для кнопки "Добавить доклад"

## Дата
2026-09-17

## Описание изменений

Кнопка "+ Добавить доклад" теперь доступна только для администраторов (пользователей с IP-адресами из списка `admin_ips` в конфигурации).

## Изменения в коде

### Файл: `src/components/TreeView.tsx`

**До:**
```tsx
{/* Add Report button */}
<div className="p-3 border-b border-gray-200 bg-gray-50">
  <button
    onClick={() => handleAdd('report', [])}
    className="w-full flex items-center justify-center gap-2 px-3 py-2 text-sm font-medium text-blue-700 bg-blue-50 hover:bg-blue-100 rounded-lg transition-colors"
  >
    <span>+</span>
    Добавить доклад
  </button>
</div>
```

**После:**
```tsx
{/* Add Report button */}
{isAdmin && (
  <div className="p-3 border-b border-gray-200 bg-gray-50">
    <button
      onClick={() => handleAdd('report', [])}
      className="w-full flex items-center justify-center gap-2 px-3 py-2 text-sm font-medium text-blue-700 bg-blue-50 hover:bg-blue-100 rounded-lg transition-colors"
    >
      <span>+</span>
      Добавить доклад
    </button>
  </div>
)}
```

## Как это работает

1. **Определение прав доступа:**
   - При загрузке приложения вызывается endpoint `/api/permissions.php`
   - Сервер проверяет IP-адрес пользователя
   - Если IP есть в списке `admin_ips` в `config.php`, возвращается `is_admin: true`
   - Иначе возвращается `is_admin: false`

2. **Передача прав в компоненты:**
   - В `App.tsx` состояние `isAdmin` устанавливается на основе ответа сервера
   - Значение `isAdmin` передается в компонент `TreeView` через props

3. **Условное отображение:**
   - Кнопка "+ Добавить доклад" отображается только если `isAdmin === true`
   - Для обычных пользователей кнопка полностью скрыта

## Безопасность

### Защита на стороне клиента
- Кнопка скрыта для не-администраторов
- Предотвращает случайное использование функций

### Защита на стороне сервера
- Endpoint `/api/permissions.php` проверяет IP-адрес
- Все административные операции требуют прав администратора
- При попытке выполнить операцию без прав возвращается ошибка 403

### Рекомендации
- Используйте HTTPS для защиты IP-адресов при передаче
- Регулярно проверяйте список `admin_ips`
- Ведите лог административных действий в `actions.log`

## Решение проблем

### Проблема: Кнопка не видна даже для администратора

**Возможные причины:**
1. IP-адрес не добавлен в список `admin_ips`
2. Кэш браузера не очищен
3. Ошибка в конфигурации

**Решение:**
1. Проверить файл `config.php` и добавить свой IP
2. Очистить кэш браузера (Ctrl + Shift + Delete)
3. Перезагрузить страницу (Ctrl + F5)
4. Проверить консоль браузера (F12) на наличие ошибок

### Проблема: Кнопка видна для не-администратора

**Возможные причины:**
1. Загружена старая версия `TreeView.tsx`
2. Кэш браузера не очищен

**Решение:**
1. Убедиться, что загружены обновленные файлы из `dist/`
2. Очистить кэш браузера
3. Перезагрузить страницу с принудительным обновлением
