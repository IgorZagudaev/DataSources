# Инструкция по развёртыванию обновлённой версии

## Что обновлено

1. **Гибридный режим** - переключение между localStorage и PostgreSQL
2. **Автоматическая синхронизация** - все изменения сохраняются в БД
3. **Импорт через API** - массовый импорт данных в PostgreSQL
4. **Полная интеграция** - все CRUD операции работают с БД

## Файлы для обновления на сервере

### 1. Frontend (dist/)

Замените все файлы в `C:/web/sites/DataSources/`:
```bash
# Скопируйте содержимое dist/ в корень сайта
cp -r dist/* C:/web/sites/DataSources/
```

Или вручную:
- `dist/index.html` → `C:/web/sites/DataSources/index.html`
- `dist/assets/*` → `C:/web/sites/DataSources/assets/`

### 2. Backend (api/)

Замените файл API:
```bash
cp backend/api/index.php C:/web/sites/DataSources/api/index.php
```

### 3. Проверка структуры

Убедитесь, что структура такая:
```
C:/web/sites/DataSources/
├── index.html
├── assets/
│   ├── index-*.js
│   └── index-*.css
└── api/
    ├── index.php          ← ОБНОВИТЬ
    ├── config.php
    └── Database.php
```

## Тестирование после развёртывания

### 1. Проверьте фронтенд
```
http://10.64.8.68/DataSources/
```
Должен появиться переключатель режимов в шапке.

### 2. Проверьте API
```
http://10.64.8.68/DataSources/api/reports
```
Должен вернуться JSON с данными из БД.

### 3. Тест переключения режимов
1. Откройте сайт
2. Нажмите **"PostgreSQL"** - данные загрузятся из БД
3. Добавьте новый доклад
4. Обновите страницу (F5) - доклад должен остаться
5. Нажмите **"Локальный"** - переключитесь на localStorage
6. Нажмите **"PostgreSQL"** - вернитесь в режим БД
7. Проверьте, что данные из БД на месте

### 4. Тест импорта
1. Переключитесь в режим **"PostgreSQL"**
2. Нажмите **"Импорт"**
3. Вставьте JSON или загрузите файл
4. Нажмите **"Импортировать"**
5. Проверьте, что данные появились в БД

### 5. Проверка в БД
```sql
-- Проверьте количество записей
SELECT COUNT(*) FROM reports;
SELECT COUNT(*) FROM sections;
SELECT COUNT(*) FROM notes;

-- Проверьте последние записи
SELECT * FROM reports ORDER BY created_at DESC LIMIT 5;
```

## Решение проблем

### Переключатель не появляется
- Очистите кэш браузера (Ctrl+Shift+R)
- Проверьте, что загружен новый `index.html`
- Проверьте консоль браузера на ошибки

### Данные не сохраняются в БД
- Откройте консоль браузера (F12)
- Перейдите на вкладку **Network**
- Выполните любое действие (добавление/редактирование)
- Найдите запрос к `/DataSources/api/import`
- Проверьте статус ответа (должен быть 200)
- Проверьте тело ответа (должно быть `{"success":true}`)

### Ошибки API
- Проверьте логи Apache: `C:/web/Apache24/logs/error.log`
- Проверьте логи PHP (если включены)
- Проверьте подключение к БД в `config.php`
- Убедитесь, что все таблицы созданы

### Данные не загружаются из БД
- Проверьте, что API доступен: `http://10.64.8.68/DataSources/api/reports`
- Проверьте, что в БД есть данные
- Проверьте консоль браузера на ошибки

## Откат изменений

Если что-то пошло не так, можно откатиться:

### 1. Восстановите старые файлы
```bash
# Если есть бэкап
cp -r backup/* C:/web/sites/DataSources/
```

### 2. Очистите localStorage
В консоли браузера:
```javascript
localStorage.clear();
```

### 3. Перезагрузите страницу
```
Ctrl+Shift+R (жёсткая перезагрузка)
```
