# Автоматическое центрирование выбранной строки

## Описание функции

При выборе строки в иерархическом дереве и открытии второй панели (с деталями, формой или подтверждением удаления), выбранная строка автоматически центрируется по вертикали в первой панели (дереве).

## Как это работает

1. **Отслеживание выбора**: При клике на элемент дерева вызывается функция `onSelect`, которая устанавливает `selectedId`
2. **Центрирование**: Срабатывает `useEffect`, который отслеживает изменение `selectedId`
3. **Прокрутка**: Выбранный элемент прокручивается в центр видимой области с плавной анимацией

## Технические детали

### Добавленные элементы:

1. **Ref для контейнера дерева**:
```typescript
const treeContainerRef = useRef<HTMLDivElement>(null);
```

2. **Data-атрибут для элементов**:
```typescript
<div data-node-id={id}>
```

3. **Effect для центрирования**:
```typescript
useEffect(() => {
  if (!selectedId || !treeContainerRef.current) return;
  
  setTimeout(() => {
    const selectedElement = treeContainerRef.current?.querySelector(`[data-node-id="${selectedId}"]`);
    if (selectedElement) {
      selectedElement.scrollIntoView({
        behavior: 'smooth',
        block: 'center'
      });
    }
  }, 100);
}, [selectedId]);
```

### Параметры прокрутки:

- `behavior: 'smooth'` - плавная анимация прокрутки
- `block: 'center'` - центрирование элемента по вертикали
- Задержка 100мс - ожидание завершения рендеринга

## Преимущества

1. **Улучшенная навигация**: Пользователь сразу видит выбранный элемент в центре экрана
2. **Плавная анимация**: Smooth scroll создаёт приятный UX
3. **Автоматизация**: Не требует ручного прокручивания дерева
4. **Контекст**: Выбранный элемент всегда виден вместе с окружающими элементами

## Пример использования

1. Пользователь выбирает элемент "Показатель 1" в глубине дерева
2. Открывается вторая панель с деталями
3. Дерево автоматически прокручивается так, чтобы "Показатель 1" оказался по центру
4. Пользователь видит выбранный элемент и контекст вокруг него

## Настройка

### Изменение скорости анимации

Измените параметр `behavior`:
```typescript
behavior: 'auto'  // Мгновенная прокрутка без анимации
behavior: 'smooth' // Плавная анимация (по умолчанию)
```

### Изменение позиции центрирования

Измените параметр `block`:
```typescript
block: 'start'   // Элемент вверху видимой области
block: 'center'  // Элемент по центру (по умолчанию)
block: 'end'     // Элемент внизу видимой области
block: 'nearest' // Ближайшая граница
```

### Изменение задержки

Измените значение `setTimeout`:
```typescript
setTimeout(() => {
  // ...
}, 100); // Задержка в миллисекундах
```

## Решение проблем

### Проблема: Центрирование не работает
**Решение:** Убедитесь, что:
1. `treeContainerRef` привязан к контейнеру дерева
2. Элементы дерева имеют атрибут `data-node-id`
3. `selectedId` корректно устанавливается при выборе

### Проблема: Прокрутка слишком быстрая
**Решение:** Увеличьте задержку в `setTimeout` или измените `behavior` на `'auto'`

### Проблема: Элемент не центрируется точно
**Решение:** Проверьте, что контейнер дерева имеет правильную высоту и `overflow-y: auto`
