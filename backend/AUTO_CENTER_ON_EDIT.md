# Автоматическое центрирование при редактировании

## Описание функции

При нажатии кнопки редактирования на строке в иерархическом дереве, эта строка автоматически центрируется по вертикали в первой панели (дереве), даже если вторая панель уже открыта.

## Как это работает

1. **Отслеживание редактирования**: При клике на кнопку редактирования вызывается функция `onEdit`, которая устанавливает `formState` с данными редактируемого элемента
2. **Передача ID**: ID редактируемого элемента передается в TreeView через prop `editingId`
3. **Центрирование**: Срабатывает `useEffect`, который отслеживает изменение `editingId`
4. **Прокрутка**: Редактируемый элемент прокручивается в центр видимой области с плавной анимацией

## Технические детали

### Изменения в TreeView:

1. **Добавлен prop `editingId`**:
```typescript
interface TreeViewProps {
  reports: Report[];
  selectedId: string | null;
  editingId?: string | null;  // <-- Новый prop
  onSelect: (id: string, type: string) => void;
  // ... остальные props
}
```

2. **Добавлен useEffect для центрирования при редактировании**:
```typescript
useEffect(() => {
  if (!editingId || !treeContainerRef.current) return;
  
  setTimeout(() => {
    const editingElement = treeContainerRef.current?.querySelector(`[data-node-id="${editingId}"]`);
    if (editingElement) {
      editingElement.scrollIntoView({
        behavior: 'smooth',
        block: 'center'
      });
    }
  }, 100);
}, [editingId]);
```

### Изменения в App.tsx:

Передача `editingId` в TreeView:
```typescript
<TreeView
  reports={reports}
  selectedId={selectedId}
  editingId={formState?.editData?.id || null}  // <-- Передаем ID редактируемого элемента
  onSelect={handleSelect}
  onAdd={handleAdd}
  onEdit={handleEdit}
  onDelete={handleDelete}
  onMoveUp={handleMoveUp}
  onMoveDown={handleMoveDown}
/>
```

## Разница между selectedId и editingId

- **selectedId**: Устанавливается при выборе строки (клик на название). Сбрасывается при открытии формы редактирования/добавления/удаления
- **editingId**: Устанавливается при открытии формы редактирования. Берется из `formState.editData.id`

## Пример использования

### Сценарий 1: Выбор строки
1. Пользователь кликает на название элемента в дереве
2. Устанавливается `selectedId`
3. Открывается панель деталей
4. Выбранная строка центрируется (срабатывает useEffect по `selectedId`)

### Сценарий 2: Редактирование строки
1. Пользователь кликает на кнопку редактирования (✎)
2. Устанавливается `formState` с данными элемента
3. `selectedId` сбрасывается в null
4. Открывается форма редактирования
5. `editingId` устанавливается из `formState.editData.id`
6. Редактируемая строка центрируется (срабатывает useEffect по `editingId`)

### Сценарий 3: Редактирование при открытой панели деталей
1. Панель деталей уже открыта (выбран элемент)
2. Пользователь кликает на кнопку редактирования другого элемента
3. `selectedId` сбрасывается, `editingId` устанавливается
4. Форма редактирования открывается вместо панели деталей
5. Редактируемая строка центрируется

## Преимущества

1. **Консистентность**: Центрирование работает как при выборе, так и при редактировании
2. **Удобство**: Пользователь всегда видит редактируемый элемент в центре экрана
3. **Плавность**: Smooth scroll создает приятный UX
4. **Автоматизация**: Не требуется ручная прокрутка дерева

## Настройка

### Изменение скорости анимации

Измените параметр `behavior`:
```typescript
behavior: 'auto'  // Мгновенная прокрутка без анимации
behavior: 'smooth' // Плавная анимация (по умолчанию)
```

### Изменение позиции центрирования

Измените параметр `block`:
```typescript
block: 'start'   // Элемент вверху видимой области
block: 'center'  // Элемент по центру (по умолчанию)
block: 'end'     // Элемент внизу видимой области
block: 'nearest' // Ближайшая граница
```

### Изменение задержки

Измените значение `setTimeout`:
```typescript
setTimeout(() => {
  // ...
}, 100); // Задержка в миллисекундах
```

## Решение проблем

### Проблема: Центрирование не работает при редактировании
**Решение:** Убедитесь, что:
1. `editingId` передается в TreeView из App.tsx
2. `formState.editData.id` содержит корректный ID
3. Элементы дерева имеют атрибут `data-node-id`

### Проблема: Центрирование срабатывает дважды
**Решение:** Это нормальное поведение. При редактировании:
1. Сначала срабатывает центрирование по `selectedId` (если элемент был выбран)
2. Затем срабатывает центрирование по `editingId`

### Проблема: Элемент не центрируется точно
**Решение:** Проверьте, что:
1. Контейнер дерева имеет правильную высоту
2. Установлен `overflow-y: auto`
3. `treeContainerRef` привязан к правильному элементу
