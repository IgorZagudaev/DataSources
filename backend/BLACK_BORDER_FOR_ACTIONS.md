# Чёрная рамка для действий добавления и удаления

## Описание

Добавлена чёрная рамка для элементов, над которыми производятся действия добавления или удаления. Теперь рамка отображается не только для выбранных и редактируемых элементов, но и для элементов, к которым добавляется дочерний элемент или которые удаляются.

## Проблема

Ранее чёрная рамка отображалась только при:
- Выборе элемента (клик по названию)
- Редактировании элемента (нажатие на карандаш)

При нажатии на кнопки добавления или удаления рамка исчезала, так как `selectedId` сбрасывалался в `null`.

## Решение

Добавлено состояние `actionId` в компоненте `App`, которое отслеживает элемент, над которым производится действие:

- **При добавлении** - подсвечивается родительский элемент (тот, к которому добавляется дочерний)
- **При удалении** - подсвечивается удаляемый элемент

## Реализация

### 1. Добавлено состояние actionId в App.tsx

```typescript
const [actionId, setActionId] = useState<string | null>(null);
```

### 2. Обновлены обработчики действий

**handleAdd** - подсвечивает родительский элемент:
```typescript
const handleAdd = (type: string, parentIds: string[]) => {
  // ...
  const parentId = parentIds.length > 0 ? parentIds[parentIds.length - 1] : null;
  setActionId(parentId);
  // ...
};
```

**handleDelete** - подсвечивает удаляемый элемент:
```typescript
const handleDelete = (id: string, type: string, parentIds: string[]) => {
  // ...
  setActionId(id);
  // ...
};
```

**handleSelect, handleEdit, handleCloseDetail** - сбрасывают actionId:
```typescript
setActionId(null);
```

### 3. Передача actionId в TreeView

```typescript
<TreeView
  reports={reports}
  selectedId={selectedId}
  editingId={formState?.editData?.id || null}
  actionId={actionId}  // ← Новый параметр
  // ...
/>
```

### 4. Обновлён интерфейс TreeViewProps

```typescript
interface TreeViewProps {
  // ...
  actionId?: string | null;
  // ...
}
```

### 5. Обновлён интерфейс TreeNodeItemProps

```typescript
interface TreeNodeItemProps {
  // ...
  isAction?: boolean;
  // ...
}
```

### 6. Обновлена функция TreeNodeItem

```typescript
function TreeNodeItem({
  // ...
  isAction = false,
  // ...
}: TreeNodeItemProps) {
  // ...
}
```

### 7. Обновлено условие для отображения рамки

```typescript
className={`... ${isSelected || isEditing || isAction ? 'ring-2 ring-black ring-offset-1 relative z-10' : ''}`}
```

### 8. Добавлена передача isAction во все TreeNodeItem

Для всех элементов дерева добавлена передача параметра `isAction`:

```typescript
<TreeNodeItem
  // ...
  isSelected={selectedId === report.id}
  isEditing={editingId === report.id}
  isAction={actionId === report.id}  // ← Новый параметр
  // ...
/>
```

## Как это работает

### Сценарий 1: Добавление дочернего элемента

1. Пользователь нажимает кнопку "+" на элементе "Раздел 1"
2. Устанавливается `actionId = id_раздела_1`
3. Открывается форма добавления
4. Элемент "Раздел 1" получает `isAction = true`
5. Отображается чёрная рамка вокруг "Раздел 1"

### Сценарий 2: Удаление элемента

1. Пользователь нажимает кнопку "✕" на элементе "Справка 1"
2. Устанавливается `actionId = id_справки_1`
3. Открывается диалог подтверждения удаления
4. Элемент "Справка 1" получает `isAction = true`
5. Отображается чёрная рамка вокруг "Справка 1"

### Сценарий 3: Переход между действиями

1. Пользователь выбирает элемент A (`selectedId = A`)
2. Пользователь нажимает редактирование элемента B (`editingId = B`)
3. Элемент A теряет рамку (`isSelected = false`)
4. Элемент B получает рамку (`isEditing = true`)
5. Пользователь нажимает удаление элемента C (`actionId = C`)
6. Элемент B теряет рамку (`isEditing = false`)
7. Элемент C получает рамку (`isAction = true`)

## Обновлённые элементы

Рамка при действиях отображается для всех типов элементов:

- ✅ Доклады (report) - при добавлении раздела, удалении доклада
- ✅ Разделы (section) - при добавлении справки, удалении раздела
- ✅ Справки (note) - при добавлении блока/показателя/источника, удалении справки
- ✅ Блоки справок (noteBlock) - при добавлении показателя, удалении блока
- ✅ Показатели (indicator) - при добавлении разреза, удалении показателя
- ✅ Разрезы (slice) - при добавлении источника, удалении разреза
- ✅ Источники (source) - при удалении источника

## Технические детали

### Сброс actionId

`actionId` сбрасывается в `null` при:
- Выборе элемента (`handleSelect`)
- Редактировании элемента (`handleEdit`)
- Закрытии панели деталей (`handleCloseDetail`)

Это гарантирует, что рамка не остаётся на элементе после завершения действия.

### Приоритет отображения рамки

Рамка отображается, если хотя бы одно из условий истинно:
- `isSelected === true` (элемент выбран)
- `isEditing === true` (элемент редактируется)
- `isAction === true` (над элементом производится действие)

```typescript
${isSelected || isEditing || isAction ? 'ring-2 ring-black ring-offset-1 relative z-10' : ''}
```

### Z-index для рамки

Добавлены классы `relative z-10` для поднятия элемента над соседними, чтобы рамка не перекрывалась:

```typescript
className={`... ${isSelected || isEditing || isAction ? 'ring-2 ring-black ring-offset-1 relative z-10' : ''}`}
```

## Преимущества

1. **Постоянная визуальная индикация** - рамка отображается при любом действии с элементом
2. **Улучшенный UX** - пользователь всегда видит, с каким элементом работает
3. **Контекст действия** - при добавлении видно, к какому элементу добавляется дочерний
4. **Предотвращение ошибок** - при удалении видно, какой элемент будет удалён
5. **Совместимость с существующей логикой** - не требует изменения логики выбора/редактирования

## Тестирование

### Тест 1: Добавление дочернего элемента

1. Найдите элемент в дереве
2. Нажмите кнопку "+" для добавления дочернего элемента
3. Убедитесь, что родительский элемент получил чёрную рамку
4. Отмените добавление или завершите его
5. Убедитесь, что рамка исчезла

### Тест 2: Удаление элемента

1. Найдите элемент в дереве
2. Нажмите кнопку "✕" для удаления элемента
3. Убедитесь, что удаляемый элемент получил чёрную рамку
4. Отмените удаление или подтвердите его
5. Убедитесь, что рамка исчезла (или элемент удалён)

### Тест 3: Переход между действиями

1. Выберите элемент A
2. Убедитесь, что рамка на элементе A
3. Нажмите редактирование на элементе B
4. Убедитесь, что рамка переместилась на элемент B
5. Нажмите удаление на элементе C
6. Убедитесь, что рамка переместилась на элемент C

### Тест 4: Все типы элементов

Проверьте отображение рамки при действиях для всех типов элементов:
- Доклады
- Разделы
- Справки
- Блоки справок
- Показатели
- Разрезы
- Источники
